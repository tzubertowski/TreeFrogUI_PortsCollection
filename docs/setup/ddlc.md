# Doki Doki Literature Club

The Ports Collection includes the FroggyDDLC Libretro port, based on the
[FroggyDDLC](https://github.com/Synaps33/FroggyDDLC) project. The launcher
includes the engine and game scripts, but not DDLC's copyrighted images, music,
or fonts.

Download `FroggyDDLC-GameData.zip` from the upstream project's
[Releases](https://github.com/Synaps33/FroggyDDLC/releases) and extract its
`assets/` directory here:

```text
roms/ports/ddlc/game/assets/
```

Keep the directory tree from the archive intact. The launcher checks for
`assets/fonts/F25_Bank_Printer.ttf`; the game needs the full `assets/` folder
for its art, fonts, music, and sound effects. It does not copy or overwrite
existing save files.

Find **Doki Doki Literature Club** in **Games → Ports**. The port targets
320×240. Controls use the D-pad to navigate, A to advance/confirm, B to back,
X or SELECT to toggle text outlines, Y for the pause menu, and START for
auto-forward.

The game contains psychological horror and depicts suicide and self-harm.
Please review DDLC's content warnings before playing.
