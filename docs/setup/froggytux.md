# SuperTux

The Ports Collection includes FroggyTux, a SuperTux 0.1.3 Libretro port from
[Synaps33/FroggyTux](https://github.com/Synaps33/FroggyTux). The game data is
included with the port; no separate game files are needed. The core renders at
320x240 RGB565; the frontend scales it to the panel.

Launch **SuperTux** from **Games → Ports**. The port keeps settings and saves
in `roms/ports/froggytux/.supertux/`.

| Button | Action |
| --- | --- |
| D-pad | Move and navigate menus |
| A | Jump / confirm |
| B | Action, run, or fireball |
| Y | Confirm / enter a level on the world map |
| Start or X | Pause, back, or skip the intro |
| L / R | Alternate jump / action |

The port does not include music playback. Sound effects are included.
