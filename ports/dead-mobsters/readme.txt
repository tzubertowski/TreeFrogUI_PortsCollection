B) Getting Started
---------------------------------------------
Unzip the download to a directory and then 
run 'mobsters.bat'. If for some reason 
that doesn't work, open the MSDOS CONSOLE and 
try the following:

Example:
		
c:\mobsters\> fxi -f -b mobsters.dcb

or you can run Dead Mobsters in a window...

c:\mobsters\> fxi -w -b mobsters.dcb

---------------------------------------------
C) Keys
---------------------------------------------
Key                    Action
---                    ------
Enter..................Start Game
ESCAPE.................Exit Game
ALT & X................Exit Game
Space..................Jump
Left Arrow Key.........Walk Left
Right Arrow Key........Walk Right
1 - 4 Number Keys......Select Your Weapon
Ctrl...................Shoot Your Weapon

Cheats:

Press L             = Warp to next level  
Press K             = Full ammo
Press M + O + B     = Toggles infinite lives
